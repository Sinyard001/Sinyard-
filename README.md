# 智能合同工作台（Contract Workbench）

一个可运行的“审查 → 问答 → 比对 → 管理”一体化合同工作台：

1. **NLP 条款自动分类与标注**：自动把合同拆成逐条条款，识别并标注违约责任、争议解决、保密义务、知识产权、付款条款等 13 类常见条款。
2. **风险分级 + 多立场审查**：输出综合风险指数与高/中/低分级，并从甲方、乙方两个签约立场分别呈现“需关注 / 相对有利”。
3. **缺失条款智能补漏**：自动识别缺项，生成可直接复制的拟补条款。
4. **合同要素自动提取**：提取甲方乙方、合同金额、签订日期、合同期限、付款计划、争议解决方式等台账字段。
5. **智能问答**：基于当前合同做本地语义检索，回答“违约责任怎么约定的”“付款计划是什么”“有哪些风险”等。
6. **版本比对**：按“第X条”对齐两个版本，标出修改 / 新增 / 删除，并呈现风险增减。
7. **台账管理**：把多份合同保存到浏览器本地台账，支持导出 CSV 用 Excel 打开。

项目同时提供命令行工具和 **黑 / 白 / 红配色的网页版**。

## 技术实现

- 条款切分：识别“第一条 / 第 1 条”等条文编号，保留原文位置。
- 中文特征：不依赖分词库，使用字符 n-gram（2~4 字滑动片段）提取语义特征。
- 分类模型：自研 softmax 逻辑回归（NumPy 实现），在约 1,256 条人工整理条款语料上训练；留出法验证 251 条样本准确率约 100%（语料内部评测，仅供参考）。
- 风险引擎：规则可解释，风险建议关联《民法典》《仲裁法》等常见审查依据。
- 要素提取：正则 + 中文数字解析，输出结构化台账字段。
- 智能问答：本地意图识别 + 字符 n-gram 语义检索（不依赖外部大模型，数据不出本机）。
- 版本比对：difflib 文本差异 + 条文编号对齐。

## 快速开始

环境要求：Python 3.10+，仅依赖 NumPy。

### 方式一：网页版（推荐体验）

双击运行 `启动网页版.bat`，脚本会自动打开浏览器进入
`http://127.0.0.1:8765`。页面支持：

- 四个工作区：审查工作台、智能问答、版本比对、合同台账；
- 直接粘贴合同正文进行审查；
- 上传 `.txt` / `.docx` 合同文件；
- 一键载入演示合同；
- 审查报告内切换“条款标注 / 风险与多立场 / 台账要素 / 缺失补漏”；
- 问答区提供快捷提问；
- 版本比对区可直接载入旧版/修订版演示；
- 台账保存在浏览器本地，可导出 CSV。

也可以在命令行手动启动：

```bash
python webapp.py
```

### 方式二：命令行

```bash
# 审查演示合同并输出报告
python -m contract_review.cli data/sample_contract.txt --output-dir ../../

# 审查自己的合同（支持 .txt / .docx）
python -m contract_review.cli 你的合同.docx --title "合同名称"

# 运行端到端测试
python -m unittest discover -s tests -v
```

报告会生成三个文件：

- `*.html`：可视化标注报告（彩色条款标签 + 风险卡片），适合直接查看；
- `*.md`：Markdown 文字版；
- `*.json`：机器可读的结构化数据，便于二次开发。

## 条款分类范围

定义与解释、服务内容与范围、权利与义务、付款条款、交付与验收、知识产权、保密义务、违约责任、期限与终止、不可抗力、通知与送达、争议解决、一般条款。

## 风险识别示例

| 风险 | 严重程度 | 常见依据 |
| --- | --- | --- |
| 仲裁条款未指定仲裁机构 | 高 | 《仲裁法》第 16 条 |
| 违约金/损失赔偿未量化 | 中 | 《民法典》第 585 条 |
| 付款期限模糊（“及时”“尽快”） | 中 | 合同履行确定性 |
| 单方解除权失衡 | 高 | 《民法典》第 497 条 |
| 保密义务未约定存续期 | 中 | 商业秘密保护 |

## 使用说明与边界

- 本工具用于辅助审查，不替代律师出具法律意见。正式使用前建议用真实合同样本补充语料并复核规则。
- 分类语料目前以技术开发、服务外包类合同为主，接入新行业时建议扩展 `training_data.py` 后重新训练。
- 风险规则可以按业务需要在 `risks.py` 中增删，报告会同步更新。

## 网页版自动化测试

```bash
python -m unittest tests.test_web -v
```

测试覆盖：页面与样式资源加载、粘贴文本审查、`.docx` 文件上传、要素提取、
多立场与风险分级、缺失条款补漏、智能问答、版本比对、非法输入与错误路由。

## 主要边界说明

- “智能问答”为本地语义检索与规则化问答，不是外部大模型；回答会尽量附带引用条款。
- “多立场审查”为规则化初筛，供谈判前快速定位争议点，最终谈判地位需结合行业惯例与专业判断。
- 台账数据仅保存在当前浏览器（localStorage），换浏览器或清除站点数据会丢失，请及时导出 CSV。
- 本工具输出仅供合同审查参考，不构成法律意见；重大合同请由执业律师复核。
