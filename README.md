# 我的笔记 · 简历工作台

一个本地运行的「笔记 + 简历 + 面试」一体化小工具，黑白红配色。

## 功能

- **首页**：每天同步飞书多维表格里「昨天更新」的内容，并支持随手笔记。
- **经历提炼**：把一句口语化的大学习历，生成书面、专业的简历用语。
- **简历模板**：同一份内容套用「简约 / 现代 / 经典 / 商务 / 学术」五种模板，支持自动存档、AI 润色、导出 PDF / Word。
- **岗位定制**：综合你写过的所有简历 + 经历大汇总 + 岗位 JD，自动写出一份匹配岗位的完整简历。
- **面试**：生成面试问答、设想面试官问题、回答指定问题。

## 运行方式（Windows）

1. 双击 `启动.bat`（会后台最小化运行，并自动打开浏览器）。
2. 用完后点页面右上角的「⏻ 退出」。

也可以手动运行：

```bash
python server.py
```

然后浏览器打开 <http://127.0.0.1:8787>。

## 首次配置

点右上角「⚙️ 设置」填写：

1. **飞书多维表格**：飞书开放平台的 App ID / App Secret，并给应用开通 `bitable:app` 权限、发布版本、把多维表格分享给该应用。
2. **AI 接口**：任意 OpenAI 兼容接口（OpenAI / DeepSeek / Kimi / 通义 / 智谱等），填 Base URL、API Key、模型名。

配置只保存在本机的 `config.json`，该文件已加入 `.gitignore`，不会被上传。

## 技术栈

- 前端：单文件 `index.html`（HTML + CSS + JavaScript，无外部依赖）。
- 后端：纯 Python 标准库 `server.py`（代理飞书与 AI 接口，保护密钥不被前端泄露）。

## 隐私

所有数据只保存在本机浏览器与 `config.json` 中；飞书和 AI 调用由你的电脑直连对应平台。
